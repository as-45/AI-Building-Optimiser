# Submission Deliverables — Hackathon Checklist

Repository: as-45/AI-Building-Optimiser

Required items (place in repo root or reports/ and upload to the submission portal):

1. Fully Functional Source Code
   - scripts/generate_baseline_metrics.py
   - extract_metrics.py (existing)
   - runtime_controller.py (if present in simulation/) — ensure MCP_SERVER_URL set in runtime_config.json
2. Building Models
   - simulations/baseline/*.idf and related files (existing)
3. Quantitative Savings Dashboard
   - reports/baseline_metrics.json (generated by script)
   - reports/dashboard.html (simple visual)
4. System Architecture Document
   - docs/SYSTEM_ARCHITECTURE.md
5. PoC Demo Video (max 3 minutes)
   - Show the loop: run baseline extraction -> show dashboard -> run (or simulate) control loop -> show optimized numbers
6. Presentation PDF/PPTX
   - Ensure SIH_Idea_Presentation_...pptx is updated with final numbers
7. GitHub link
   - Provide full repository URL in the submission form.

How to generate baseline_metrics.json
- From repo root:
  1. python3 -m venv .venv && source .venv/bin/activate
  2. pip install -r requirements.txt  # add any deps to requirements.txt
  3. python3 scripts/generate_baseline_metrics.py

How to serve the dashboard
- cd reports
- python3 -m http.server 8000
- Open: http://localhost:8000/dashboard.html

Notes
- If eplustbl.csv is not present, open eplustbl.htm and copy the annual MWh into reports/baseline_metrics.json manually.
- For the MCP/LLM demo: set MCP_SERVER_URL in config/runtime_config.json or as environment variable.
